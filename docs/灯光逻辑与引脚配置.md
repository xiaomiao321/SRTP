## 灯光逻辑
| 灯具名称   | 对应硬件/引脚                                    | 颜色与动作    | 状态含义                         |
| ---------- | ------------------------------------------------ | ------------- | -------------------------------- |
| 电源指示灯 | LED7（VDD 3.3V，主控板）                         | 红色常亮      | 设备已开机                       |
| 充电指示灯 | LED6（MCP73831 STAT，主控板）                    | 红色常亮      | 正在充电，充满熄灭               |
| RGB 灯     | RGB1（主控板）：R = P0.27，G = P0.26，B = P0.25，低电平点亮 | 白色呼吸      | 系统空闲/待命，等待佩戴          |
|            |                                                  | 黄色慢闪（红+绿） | 正在检测手部震颤             |
|            |                                                  | 青色慢闪（绿+蓝） | 电刺激干预正在进行中         |
|            |                                                  | 红色快闪      | 严重警报（设备故障，如电极脱落） |
| 通道状态灯 | LED4（NNC6121 GPIO2，网络 LED_CH0，刺激板）                    | 同步点亮/熄灭 | 反馈通道 0（STIMU0/1）是否正在输出 |
|            | LED5（NNC6121 GPIO5，网络 LED_CH1，刺激板）                    | 同步点亮/熄灭 | 反馈通道 1（STIMU2/3）是否正在输出 |

RGB 灯为 Everlight 19-337/R6GHBHC-A01/2T（普通 RGB，非可寻址），三个阳极接 VDD，阴极经 R52 470Ω / R53 100Ω / R54 100Ω 接 GPIO，用 nRF 的 PWM 调色和呼吸。RGB 接在 P0.25–P0.27，这几个脚靠近射频，按 nRF52832 PS 4.3.1 节只能用标准驱动（不要开高驱动）、PWM 频率 ≤ 10kHz，灯会比高驱动时暗一些。P0.09/P0.10（NFC 脚）现在接 J5 的 I2C，固件仍必须在 UICR 里把 NFCPINS 设为 GPIO。

## 按键逻辑
| 按键         | 引脚             | 类型         | 功能说明               |
| ------------ | ---------------- | ------------ | ---------------------- |
| SW3 电源开关 | 控制 Q5 栅极（主控板） | 拨动开关 | 拨动：开机/关机（开关只控制 P-MOS Q5，不走负载电流） |
| SW2 治疗键   | GPIO16 (NNC6121)，网络 KEY_START | 侧按轻触按键（EVQP7A01P） | 短按：开始/暂停治疗    |
| SW4 急停键   | GPIO15 (NNC6121)，网络 KEY_ESTOP | 侧按轻触按键（EVQP7A01P） | 短按：立即切断刺激输出 |
| RST1         | NRST (NNC6121)   | 轻触按键     | 复位刺激芯片           |
| RST          | P0.21 (nRF52832) | 轻触按键     | 复位主控               |

## 板间连接器（J1 主控板排针 / J2 刺激板排母，1.27mm 2×8）
| 针 | 信号 | 针 | 信号 |
| -- | ---- | -- | ---- |
| 1  | VOUT | 2  | VOUT |
| 3  | GND  | 4  | GND  |
| 5  | VDD 3.3V | 6 | GND |
| 7  | SPI_CLK | 8 | GND |
| 9  | SPI_MOSI | 10 | SPI_MISO |
| 11 | SPI_CS | 12 | NNC_INT（NNC GPIO17 → nRF P0.06） |
| 13 | NNC_NRST（nRF P0.07） | 14 | STIM_EN_N（nRF P0.08，低有效） |
| 15 | GND | 16 | 空 |

> 表中针号是**主控板 J1** 的针号。两块板面对面叠插时排母会镜像，所以刺激板 **J2 的针脚两两对调**：J2.n 接的是 J1 的 n±1 号针（J2.6=VDD、J2.8=SPI_CLK、J2.9=MISO、J2.10=MOSI、J2.11=NNC_INT/GPIO17、J2.12=CS、J2.13=STIM_EN_N、J2.14=NNC_NRST、J2.16=GND）。已在 PCB 上逐针核对，叠插后 16 针一一对应。
